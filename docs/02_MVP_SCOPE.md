# 02. MVP SCOPE — 1차 개발 범위

상태: 제품 범위 확정 / 구현 전. 기준은 [PRD](01_PRD.md)와 [Phase 0 결정](13_PHASE0_DECISIONS.md)이다. 여기서 MVP는 학습 루프 전체를 포함하는 1차 출시를 뜻한다. 22시간 제한은 없다.

## 포함·제외와 완료 기준

| 단계 | 기능 | 완료 기준 |
|---|---|---|
| 1차: FR-01~07 | 가입·로그인·분야별 검수 퀴즈·서버 채점·시도 기록·Vector RAG·문제 문맥 질문 | 본인 풀이 결과로 질문하고 출처 있는 답변을 받으며 기록을 복원 |
| 1차: FR-08~10 | 관련 AI 퀴즈 생성/검증·개인 문제 풀이·마이페이지·오답노트·재풀이 | 추가 풀이와 복습까지 하나의 이력으로 이어지는 전체 E2E |
| 2차: FR-11/12 | 지식 관계 지도·Graph RAG | 관계 타입·방향·근거·검증 상태를 갖춘 제한 탐색 |
| 후속: FR-13 | 취약 개념과 관계 기반 추천 | 학습 이력과 검증된 관계에 근거한 설명 가능한 추천 |

1차의 두 행은 구현 순서이며 별도 MVP 1/2 출시 범위를 뜻하지 않는다. FR-01~10과 [검증 시나리오](09_TEST_SCENARIO.md)가 모두 만족돼야 1차 완료다.

## 초기 기능 한계

- 문제 유형: 4지선다 단일 정답. 생성은 요청당 1문항이며 검증 실패 후보를 노출하지 않는다.
- 문제 기반 질문: 제출 결과에서 시작하며 본인 attempt_id로 문맥을 복원한다. 독립 CS 질문도 지원한다.
- 생성 문제: 개인 소유이며 공용 문제은행에 자동 편입하지 않는다.
- 데이터: 승인된 제한 코퍼스와 공통 concept_id를 사용한다. 최초 문서/문제 수는 구현 단계에서 결정한다.
- 인증: 이메일/비밀번호와 쿠키 세션을 기본안으로 사용한다. 실제 라이브러리·만료 설정은 미결정이다.

Graph DB, 자동 추천, 주관식/복수 정답, 제출 전 정답 힌트 모드, 관리자 UI, 랭킹·결제·소셜 기능, 임의 웹 검색과 운영 배포는 1차 범위 밖이다. 메일 인증·암호 재설정·탈퇴 자동화·보존 정책은 별도 결정 대상이다.

## 범위 변경

기능 범위 변경은 PRD·이 문서·관련 실행 계획·검증 시나리오를 함께 갱신한다. 세부 API와 데이터 제약은 [API](07_API_SPEC.md)·[ERD](06_ERD.md)를 따른다. 미구현 항목을 문서 작성이나 하네스 bootstrap 성공만으로 완료 처리하지 않는다.
