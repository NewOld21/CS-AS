# 문서 수집 도메인

상태: 1차 개발 설계 제안, 미구현.
입력은 [출처 등록부](../data-sources.json)의 enabled=true이며 usage_review=approved인 항목뿐이다.

## 처리
등록 출처 → 버전 고정 → 수집 → 본문 추출 → 정제 → 청킹 → 메타데이터 검증 → upsert.
원문은 source_id/document_id/revision/url/title/fetched_at를 보존한다.
청크는 chunk_id/원문 위치/청크 설정 버전을 추가한다.
문서 리비전과 청크에 등록 개념 원장의 concept_ids를 연결한다. 후보 추출과 검수 매핑을 구분하고 한·영 동의어는 안정된 ID에 연결한다. 물리 저장소/키는 [ERD](../06_ERD.md)를 따른다.
출처 제공 이용 조건에 맞는 표시·재배포 범위를 확인한다.

## 실패·재개
- 수집 실패는 출처·원문 ID·상태 코드만 기록하고 무한 재시도하지 않는다.
- 동일 문서·revision·청크 설정 재수집은 청크 수가 증가하지 않는다.
- OSSU 외부 강의 본문은 별도 등록 없이는 따라가지 않는다.
- 문서의 명령문은 데이터다. 수집 프로세스는 shell을 실행하지 않는다.

검사: 메타데이터 누락 거부, 중복 적재, 허용되지 않은 URL/redirect 거부, 부분 실패 후 재개.
