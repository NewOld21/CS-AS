# 00. PROJECT PROPOSAL — 프로젝트 제안서

CS/AS는 CS 퀴즈로 이해도를 확인하고, 모르는 개념을 AI에게 질문하며, 관련 문제와 복습으로 학습을 이어가는 플랫폼이다.

> CS/AS — CS를 질문하고, 이해하고, 연결하다.
> CS를 공부하다 막히는 순간, AS해 드립니다.

## 해결할 문제와 차별점

퀴즈를 푼 뒤 모르는 개념을 다른 곳에서 다시 질문하거나, 대화에서 배운 내용을 실제 문제로 확인하지 못하는 학습 단절을 줄인다. 문제·질문·관련 퀴즈·복습을 같은 개념과 이력으로 연결한다. 대상은 CS 입문자·전공 학생·기술 면접 준비자다.

## 사용자 흐름

가입·로그인 → 퀴즈 → 정답·해설 → 문제 문맥을 유지한 AS 질문 → 근거로 이해 → 관련 AI 퀴즈 → 오답 복습·마이페이지.

## 1차 개발

- 회원가입·로그인과 사용자별 학습 접근 제어.
- 분야별 검수 퀴즈, 서버 채점, 불변 풀이 기록.
- Vector RAG 질문·문제 문맥 전달·출처·근거 부족·오류 처리.
- 검색 근거 기반 AI 퀴즈 생성·검증, 개인 문제 풀이.
- 마이페이지 통계·대화 복원·오답노트·재풀이.
- 퀴즈·문서·청크의 공통 concept_id로 향후 그래프 연결 준비.

## 후속 범위

Graph RAG·지식 지도는 2차, 학습 이력 기반 관계 추천은 후속이다. 운영 배포·임의 웹 실시간 검색·랭킹·결제는 1차 범위 밖이다.

## 확정 사항과 현재 상태

기존 Vue + Spring Boot + 별도 Python RAG 선택과 22시간 제한 해제는 유지한다. C02/C03 요청에 따라 서비스 DB는 PostgreSQL, 검색 저장소는 ChromaDB로 변경했다([ADR 0004](decisions/0004-stack.md)). 로컬 DB와 C04~C07 Java migration·health·사용자 인증은 구현했다. Vue·학습 기능·Python HTTP/RAG 연결은 후속이다. [PRD](01_PRD.md)가 범위 기준이고, 구현 순서는 [로드맵](10_IMPLEMENTATION_PLAN.md), 제품 범위 결정은 [ADR 0003](13_PHASE0_DECISIONS.md)을 따른다.
