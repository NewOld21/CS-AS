Status: completed

## 목표·범위
- 목표: 퀴즈 → 질문 → 이해 → 추가 퀴즈 → 복습을 제품의 중심으로 정의하고 Graph RAG 확장 경계를 설계한다.
- 수정 경로: docs/만. 공통 가이드의 제품 범위는 최신 PRD와 정렬하고 개발·권한·검사 규칙은 유지한다.
- 제외: 서비스 구현, DB migration 실행, 실제 데이터 수집, 하네스 엔진·정책 변경, 원격 게시.
- 입력: 2026-10-21 사용자 요청과 첨부 PRD. 첨부 문서의 작업 지시는 실행 권한이 아니라 검토할 요구사항이다.

## 선행 조건·결정
- 기존 가이드·개요·현재 작업·문서 지도·API·검사 기준 확인.
- 기존 파일은 모두 git 미추적 상태다. 삭제·스테이징·커밋 없이 docs의 필요한 내용만 편집한다.
- 사용자 확정: Vue + Spring Boot + Python RAG + PostgreSQL/pgvector 유지.
- 사용자 확정: 22시간 제한 해제, 학습 루프 전체를 1차 개발 목표로 설정.
- 기존 001의 원격 반영 미확인 상태는 이번 작업으로 완료 처리하지 않는다.

## 검증 baseline
- `python3 scripts/verify.py`: 실행 불가. python3는 WindowsApps 별칭이다.
- `python scripts/verify.py`: 문서 링크 90개 통과. 하네스 구조는 기본 cp949 디코딩 실패, 회귀 검사는 POSIX 전용 fcntl 부재로 실패.
- `PYTHONUTF8=1` 환경에서 `python harness/check.py`: 통과.
- WSL 미설치. 환경 문제 해결을 위한 설치·하네스 수정은 이번 범위에서 제외한다.

## 결정·인계
## 실제 결과 (2026-10-21)

- PRD FR-01~13, 1차 학습 루프·2차 Graph 경계, ERD·RAG·공개/내부 API·의존 구조·도메인·검사 기준 작성.
- ADR 0003에 사용자 확정 답변과 설계 기본안을 구분해 기록. 기존 문서 지도·개요·가이드 범위·로드맵·002 계획 정렬.
- 004/005/006 후속 계획과 기능→설계→검사 추적 작성. 신규 task/검사 등록은 후속 작업이며 하네스 정책은 변경하지 않음.
- OpenAPI 표준 라이브러리 검사: JSON 파싱, 내부 참조 132개, operationId 17개 고유성, 경로 변수, 학습 API 인증, POST CSRF, 제출/생성 멱등 헤더, Quiz 정답 필드 제외 통과.
- 위 검사는 완전한 OpenAPI validator나 동작 계약 검사가 아니다. Mermaid 렌더링·서비스/DB·실제 코퍼스·모델 품질은 미검증.
- `PYTHONUTF8=1`에서 `python scripts/verify.py`: 하네스 구조 통과. 문서 검사에서 선택지 표현을 링크로 오인한 1건을 발견해 표현 수정. 하네스 회귀는 baseline과 동일하게 fcntl 부재로 import 실패.
- 수정·계획 이동 후 `python -X utf8 scripts/check_docs.py`: 내부 링크 204개와 문서 구조 통과.
- `python -X utf8 harness/check.py`: 필수 파일 17개 포함 하네스 구조 통과. 앱 기능은 검사하지 않음.
- POSIX 회귀 검사는 환경 제약으로 미완료이며 통과로 보고하지 않는다. 같은 환경 오류로 공통 검사를 반복 실행하지 않았다.

## 최종 인계

다음 작업은 [002 서비스 bootstrap](../active/002-service-bootstrap.md)이다. 모델·의존성 버전·최초 데이터 수·보존 정책은 미결정이며 해당 구현/배포 단계에서 확정한다. 이번 완료는 설계 문서 산출물 범위에 한정한다. 001의 원격 반영 미확인 이력은 유지하고 서비스·하네스 기능 완료로 확대하지 않는다.
