## 구현 범위와 다음 행동

이번 완료는 Java DB migration·인증 API다. 실제 퀴즈/대화/학습 저장소는 미구현이며 인증 후 해당 경로는 404다. 소유권 guard는 테스트 전용 소유자 리소스로 검증했고 후속 실제 repository 쿼리의 사용자 범위 제한은 별도로 검사해야 한다. Vue UI·Python HTTP·RAG 검색·호출 제한·운영 배포는 다음 002/004/005 범위다. 메모리 세션은 재시작 시 소멸한다. 다중 인스턴스/공유 세션은 별도 ADR이 필요하다. 기존 008 수집의 출처 승인/라이브 검증 미완료 상태는 유지한다.
