## 공동 변경 경계

- 공개 API 변경은 [07_API_SPEC](07_API_SPEC.md)와 OpenAPI·호출자·구현·검사를 함께 수정한다.
- 데이터 변경은 [06_ERD](06_ERD.md)와 migration·기존 이력 호환·전용 DB 검사를 함께 수정한다.
- 검색/모델 변경은 코퍼스·개념 매핑·모델·인덱스·평가 버전을 인계한다.
- 공통 규칙은 [08_AGENTS](08_AGENTS.md)에서만 수정한다. 영역별 AGENTS는 해당 기준으로 연결한다.
- 범위 변경은 PRD·MVP·계획·테스트에 반영하고 기술 선택은 Phase 0/후속 ADR에 이유를 남긴다.

## 인계 완료 기준

현재 동작·미구현·미결정 상태, 변경 경로와 계약, 실행 명령/결과, 환경 한계, 다음 행동을 실행 계획에 남긴다. 문서 검증을 서비스 동작 완료로 보고하지 않는다. 실제 인원/담당자·리뷰어는 팀 구성이 정해지면 표에 추가한다.
