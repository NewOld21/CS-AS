# 04. SCREEN SPEC — 화면 명세

상태: SC-01~03과 /account 인증 화면을 구현했다. SC-04~08은 /learn의 분야·퀴즈·결과·대화·생성 패널로 제공하며, C30은 SC-06 과거 결과와 SC-09~10 학습 기록·오답노트를 연결한다. 아래 경로는 Vue 라우트이며 HTTP API 경로가 아니다. [디자인 시스템](design/ui-system.md)에 토큰·반응형·검사 범위를 정리했다.

| ID·화면 | 라우트 후보 | 접근 | 주요 표시·행동 |
|---|---|---|---|
| SC-01 서비스 소개 | / | 공개 | 제품 소개·학습 흐름·가입/로그인 진입 |
| SC-02 가입 | /signup | 공개 | 이메일·비밀번호 입력, 성공 후 로그인 안내 |
| SC-03 로그인 | /login | 공개 | 로그인·검증 오류·학습 화면 진입 |
| SC-04 분야/문제 목록 | /learn | 로그인 | 분야 선택·문제 순서 이동 |
| SC-05 문제 풀이 | /learn?quiz_id=... | 로그인 | 문제·4개 선택지·답안 제출. 제출 전 정답/해설 없음 |
| SC-06 풀이 결과 | /me/attempts/:attemptId | 소유자 | 당시 선택·정오답·정답·해설·근거·AS 질문·재풀이 |
| SC-07 AS 대화 | /learn?chat_session_id=... | 소유자 | 대화 목록/복원·현재 문제 문맥·질문·근거 답변·개념·관련 문제 생성 |
| SC-11 독립 CS 학습 | /chat?session=... | 소유자 | 퀴즈 없이 자유 질문·대화 선택/복원·근거·코드 복사·모바일·실제/예제 provider 표시 |
| SC-08 생성 진행 | 대화/결과 내 패널 | 로그인 | 생성 중·검증 중·제공 불가·완료. 완료 시 SC-05로 연결 |
| SC-09 마이페이지 | /me | 로그인 | 전체/분야별 시도·정답률·최근 풀이·이력 페이지 |
| SC-10 오답노트 | /me/wrong-answers | 로그인 | 미복습/해결 필터·최근 시도·결과·재풀이 |

생성 문제도 SC-05/06을 재사용하고 AI 생성 표시를 붙인다. 공용 문제은행과 개인 문제의 접근 정책은 [PRD](01_PRD.md)를 따른다. SC-06은 본인의 RETIRED 문제 과거 결과도 표시하되 새 풀이가 불가함을 안내한다.

## 화면별 상태

| 영역 | 필수 상태·동작 |
|---|---|
| 가입/로그인 | 입력 검증·요청 중·계정/인증 실패·성공. 비밀번호/쿠키 로그 금지 |
| 문제 목록/이력 | 로딩·빈 목록·정상·오류. 필터 변경 시 페이지 범위 초기화 |
| 풀이 | 선택 전 제출 불가·제출 중 중복 클릭 방지·전송 재시도에 같은 키 유지 |
| 결과 | 새로고침 시 attempt_id로 복원. 클라이언트에서 채점값을 계산하지 않음 |
| 대화 | 초기/빈 대화·전송 중·답변·근거 부족·장애·세션 만료. 세션당 전송 직렬화 |
| 생성 | 요청 중·검증 중·ready·근거 부족·검증 실패·upstream 오류. 실패 후보 비노출 |
| 통계 | 시도 0건은 정답률 “—”로 표시, 재풀이가 포함된다는 기준 안내 |
| 복습 | NEEDS_REVIEW/RESOLVED 구분, 해결 후에도 과거 이력 접근 가능 |

## 공통 UI 계약

- 인증 가드와 별개로 서버 접근 제어를 사용한다. 재로그인 이후 허용된 학습 화면으로 연결한다.
- 답변/원문은 텍스트를 기본으로 렌더링하고, 출처는 제목·URL·근거 위치로 표시한다.
- 선택지는 키보드로 조작 가능하고 선택·정오답 상태를 색상만으로 전달하지 않는다.
- 실패 시 사용자에게 가능한 다음 행동을 표시한다. 내부 프롬프트·검증기 정보는 화면에 노출하지 않는다.
- 디자인 토큰·반응형 breakpoint·구체적인 배치/시각 디자인은 구현 단계에서 결정한다.

SC-01~10은 [사용자 흐름](03_USER_FLOW.md)·[API](07_API_SPEC.md)·[검증 시나리오](09_TEST_SCENARIO.md)와 함께 갱신한다. 지식 지도는 [RAG 가이드](14_RAG_GUIDE.md)의 2차 확장이다.
